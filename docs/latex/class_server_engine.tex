\doxysubsection{Detailed Description}
Authoritative UDP game server managing clients, combat, abilities, and world state. 

Runs a fixed 60 Hz tick loop, processes incoming packets, simulates enemies and ability entities, handles upgrade progression, and broadcasts world snapshots to connected clients.
