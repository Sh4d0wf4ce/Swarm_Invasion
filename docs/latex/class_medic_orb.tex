\doxysubsection{Detailed Description}
\doxylink{class_medic}{Medic} healing orb that moves through the map and tethers nearby units. 

Bounces off walls, interpolates toward server position, and draws energy tethers to allies and enemies within effect range. Lifetime is tracked via HP.
