\doxysubsection{Detailed Description}
GPU-\/cached tile map renderer. 

Builds a vertex array from a \doxylink{class_map_generator}{Map\+Generator} and draws the visible map tiles as colored triangles. Call \doxylink{class_map_renderer_a2a6997357b8b0feb3061356aa8b53caf}{rebuild()} when the underlying map data changes.
