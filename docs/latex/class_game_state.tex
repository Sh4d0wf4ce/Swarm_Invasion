\doxysubsection{Detailed Description}
Active gameplay state for an in-\/session multiplayer match. 

Simulates the local player, mirrors remote entities from server snapshots, manages projectiles and ability world objects, handles combat input, and renders the world plus HUD overlays including upgrade selection and session end.
