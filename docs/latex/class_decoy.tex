\doxysubsection{Detailed Description}
\doxylink{class_vanguard}{Vanguard} decoy entity that mimics the hero and explodes on destruction. 

Pulses its outline while alive, then plays an expanding cyan explosion VFX when triggered. Uses \doxylink{class_vanguard}{Vanguard} hero visuals and player faction alignment.
