\doxysubsection{Detailed Description}
Client-\/side representation of a hostile enemy unit. 

Visualizes server-\/authoritative enemy state with type-\/specific stats from \doxylink{class_enemy_registry}{Enemy\+Registry}. Position updates are driven externally; the local update step only syncs the drawable shape to the current position.
