\doxysubsection{Detailed Description}
\doxylink{class_medic}{Medic} ultimate drone with orbiting nodes and a spinning energy ring. 

Interpolates toward server position, pulses its core shape, and renders three orbiting nodes. Belongs to no combat faction and has zero radius.
