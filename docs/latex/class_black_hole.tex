\doxysubsection{Detailed Description}
\doxylink{class_juggernaut}{Juggernaut} black hole ability entity with pull-\/radius visualization. 

Uses remaining lifetime as HP and renders a pulsing purple pull ring around a dark core. Belongs to the player faction for friendly ability filtering.
