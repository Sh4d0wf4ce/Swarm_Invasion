\doxysubsection{Detailed Description}
Abstract base class for client application states. 

Each state implements the game loop hooks invoked by \doxylink{class_client_engine}{Client\+Engine}:\+ packet handling, input, simulation update, world rendering, and UI. States receive a reference to the owning engine for window and network access.
